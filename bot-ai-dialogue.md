Прототип Telegram-бота с AI-диалогом и памятью

Цель проекта

Создать работающий прототип Telegram-бота, который:
1. Ведёт диалог с пользователем на естественном языке через AI (OpenAI API / совместимый API)
2. Запоминает информацию о пользователе (имя, возраст, цели) в течение диалога
3. Использует эту информацию для персонализации следующих ответов
4. Поддерживает многосессионную память (помнит пользователя при повторных обращениях)
5. Умеет задавать уточняющие вопросы, если данных недостаточно

Этот прототип будет использоваться как демонстрационный кейс в портфолио для заказов на разработку AI-модулей для Telegram-ботов.

---

Технический стек

Язык: Python 3.11+
Telegram-фреймворк: aiogram 3.x
AI API: OpenAI API (совместимый, например Agnes AI)
База данных: SQLite (через aiosqlite)
ORM: SQLAlchemy (async)
Переменные окружения: python-dotenv
Логирование: logging

Функциональные требования

1. Команды бота

/start - Приветствие, регистрация/идентификация пользователя в БД
/reset - Сброс истории диалога и профиля пользователя
/help - Справка по командам

2. Диалог с AI

- При первом обращении бот приветствует пользователя и предлагает представиться.
- Если пользователь не представился - бот задаёт уточняющий вопрос.
- После получения имени - бот спрашивает возраст и цель обращения.
- Вся собранная информация сохраняется в профиле пользователя в БД.
- При каждом новом сообщении бот формирует промпт, который включает:
  - Системный промпт с ролью "дружелюбный помощник"
  - Данные профиля пользователя (имя, возраст, цель)
  - История последних N сообщений (контекст диалога)
- AI отвечает с учётом профиля и контекста.
- Если пользователь спрашивает что-то, что требует уточнения - бот задаёт уточняющие вопросы.

3. Память и хранение

- Таблица users: id, telegram_id, first_name, age, goal, created_at, updated_at.
- Таблица messages: id, user_id, role (user/assistant), content, created_at.
- При каждом сообщении сохраняется запись в messages.
- При повторном обращении - бот загружает профиль пользователя из БД и последние 10 сообщений.

4. Обработка ошибок

- Недоступность AI API - бот отвечает "Сервис временно недоступен, попробуйте позже".
- Невалидный ответ от AI - бот логирует ошибку и отвечает "Не удалось обработать запрос".
- Таймауты - повторные попытки с экспоненциальной задержкой (retry 3 раза).

5. Логирование

- Все запросы к AI логируются (без содержимого сообщений).
- Ошибки логируются с уровнем ERROR.
- Действия пользователя (команды) логируются с уровнем INFO.

Требования к AI-промпту

Системный промпт:

Ты - дружелюбный AI-помощник. Твоя задача - вести диалог с пользователем, учитывая его профиль и историю общения. Отвечай кратко, по делу, но с теплотой. Если не знаешь ответа - честно скажи, что не знаешь. Не выдумывай факты. Если данных недостаточно - задай уточняющий вопрос. Подстраивай тон под пользователя: если он новичок - объясняй простыми словами, если опытный - давай больше деталей.

Промпт для персонализации:

Информация о пользователе:
- Имя: {first_name}
- Возраст: {age}
- Цель: {goal}

История диалога (последние 10 сообщений):
{history}

Ответь пользователю на его последнее сообщение с учётом его профиля и контекста диалога. Будь вежливым, дружелюбным и полезным.

Критерии приёмки

1. Бот запускается и отвечает на команду /start
2. При первом обращении бот спрашивает имя пользователя
3. После получения имени - бот запоминает его и использует в ответах
4. Бот запоминает информацию о пользователе (имя, возраст, цель)
5. При повторном обращении бот узнаёт пользователя и помнит контекст
6. AI отвечает персонализированно (обращается по имени)
7. Бот хранит историю диалога в БД
8. Команда /reset сбрасывает профиль и историю
9. При недоступности AI API - бот не падает, а выдаёт понятную ошибку
10. Всё работает локально, с минимальными доработками для деплоя

Инструкция по запуску (README.md)

# AI Dialogue Bot

Telegram-бот с AI-диалогом, персонализацией и памятью.

## Установка

1. Клонируйте репозиторий:
   git clone git@github.com:your-username/ai-dialogue-bot.git
   cd ai-dialogue-bot

2. Создайте виртуальное окружение и активируйте:
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate     # Windows

3. Установите зависимости:
   pip install -r requirements.txt

4. Скопируйте .env.example в .env и заполните:
   cp .env.example .env
   - BOT_TOKEN - получите у @BotFather в Telegram
   - OPENAI_API_KEY - ваш ключ от OpenAI или Agnes AI
   - OPENAI_BASE_URL - https://apihub.agnes-ai.com/v1 для Agnes AI

5. Создайте папку для БД:
   mkdir data

6. Запустите бота:
   python main.py

## Команды

- /start - начать диалог
- /reset - сбросить профиль и историю
- /help - справка

Датасет для тестирования

Для проверки работы используй следующие тестовые сценарии:

1. Пользователь пишет /start -> бот приветствует и спрашивает имя.
2. Пользователь пишет имя -> бот запоминает и спрашивает возраст.
3. Пользователь пишет возраст -> бот запоминает и спрашивает цель.
4. Пользователь пишет цель -> бот запоминает и предлагает задать вопрос.
5. Пользователь задаёт вопрос -> бот отвечает с учётом профиля.
6. Пользователь пишет /reset -> бот сбрасывает всё и прощается.
7. Пользователь снова пишет /start -> бот снова спрашивает имя (как нового пользователя).
